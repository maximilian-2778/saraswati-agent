# Saraswati Agent — 简历版 MVP 1.0

## 产品定位

Saraswati Agent 是一个面向长篇角色扮演的 Agent 原生聊天客户端。它将分层记忆检索、结构化世界状态、工具驱动生成和生成后一致性审计组合在一起。

本版本的目标是形成一个完整、可演示的简历项目，不追求替代 SillyTavern 的全部功能。

## 核心用户流程

1. 用户在独立的“角色库”和“世界书库”维护可复用模板。
2. 用户创建角色扮演存档，填写标题并多选需要复制的角色与世界书。
3. 用户从 React 客户端发送消息。
4. 后端保存用户消息，并从角色档案、触发的世界书、近期对话、相关记忆和已确认状态中组装长度受控的上下文。
5. 模型可以通过 Agent Runtime 调用记忆和状态工具。
6. Runtime 执行工具，再让模型根据工具结果生成最终回复。
7. 回复完成后生成带原文指纹的楼层叶子，并把同级森林根逐级压缩为章节和篇章。
8. 显式时间进入时间线；物品、人物、场景和悬念变化进入可审核台账。
7. 后端保存 AI 回复，创建情节记忆，并执行一致性检查。
8. 客户端同时显示正文、记忆来源、状态变更建议、审计问题和执行轨迹。
9. 用户决定批准或拒绝状态变更建议。

## 1.0 包含的功能

- 多个本地聊天存档。
- 每个存档可拥有多个角色与世界书私有副本，副本与原始模板相互隔离。
- 兼容 OpenAI Chat Completions 和 Embeddings 格式的模型接口。
- 未配置模型 API 时提供明确的未连接状态，并阻止产生伪造回复。
- 有最大步数、轨迹日志和失败处理的工具调用循环。
- 近期原文窗口、摘要森林，以及情节、事实、摘要、隐性四种检索记忆。
- 漏摘/失效覆盖诊断、消息改写后的祖先失效和分支重建。
- 多视角 Embedding、关键词、重要度与时间组成的分档混合 RAG。
- 以已批准变更事件为真源、可重新回放的结构化状态投影。
- 层级场景树、当前位置，以及可选择注入的 NPC 关系图谱。
- 可选独立 reranker 服务和失败降级。
- 用户批准或拒绝状态变更。
- 带证据的基础数值一致性审计。
- 包含聊天、存档、状态、记忆、审计和轨迹面板的 React 客户端。
- 可动态生效的模型、生成、Agent、RAG、界面与隐私设置中心。
- SQLite 持久化、后端自动化测试、示例数据和本地运行说明。

## 1.0 暂不包含

- 用户账号、权限、计费和云端多租户。
- 分布式任务、Redis、Kubernetes 和高并发生产部署。
- 模型训练或微调。
- 独立部署的通用向量数据库。
- 完整的 SillyTavern 角色卡和世界书兼容。
- 无法追溯或撤销的自动状态修改。
- 复杂的多 Agent 角色编排。

## 验收标准

- 应用可以按文档在本地启动。
- 用户可以创建存档、发送消息，并在重启后保留聊天历史。
- 没有 API Key 时仍可管理本地资料，发送消息会引导用户完成模型配置。
- 配置兼容接口后，Agent Runtime 可以调用工具并生成最终回复。
- 记忆可以创建、检索、查看，并追溯到来源消息。
- 摘要森林能展示父子层级、覆盖率和当前注入节点；楼层改写后旧分支不再进入上下文或 RAG。
- Agent 提取的状态变更会自动采用，并能在修改记录中一键撤销。
- 数值矛盾能够生成可见的审计问题。
- 后端测试覆盖健康检查、存档、消息、记忆检索和状态批准。
- 设置修改后立即重建 Runtime，API Key 不通过读取接口返回明文。
- README 包含架构、演示步骤、指标和简历描述。
