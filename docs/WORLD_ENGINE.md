# 世界编年

Saraswati 的世界编年用于维护“当前镜头之外仍在发展”的故事状态。它与地点、NPC、世界书和长期记忆共享同一个故事数据库，不建立第二套人物或地点档案。

第一阶段包含：

- 世界摘要与推演轮次
- 势力、关系、影响力和最近行动
- 冲突/进展两类持续事件及其阶段、等级和下一步压力
- 公告、消息、传闻和舆情
- 可上升、持平或回落的宏观趋势
- 手动推进，以及默认关闭的随剧情自动推进
- 将当前世界状态注入下一轮角色扮演上下文

## 状态链

每次推进都在 `world_evolutions` 写入一条不可变完整快照，并记录：

- 前一世界状态摘要
- 来源用户消息与助手消息
- 两条消息的内容指纹
- 推演后的完整世界状态

读取当前世界时，服务从初始状态顺序验证状态链。某条剧情被改写后，其消息指纹不再匹配，该条推演及依赖它的后续分支会停止生效；记录本身仍保留用于诊断，不会静默覆盖历史。

## 推演边界

- 自动推进是可选后处理，失败不会吞掉已经生成的正文。
- 推演器读取已有地点、NPC 和启用的故事世界书，但不会复制这些资料成为另一套档案。
- 世界状态只描述宏观背景、持续事项和公开传播的信息，不替玩家行动，也不向正文泄漏角色未知的秘密。
- 手动编辑现状不会增加世界轮次；只有真正推进才增加轮次。

## 来源说明

世界编年使用 Saraswati 自身的 Python/FastAPI/SQLAlchemy/React 架构独立实现，通过持续事件、势力、传闻、状态注入和存档点维护镜头之外的世界变化，不依赖第三方客户端的浏览器运行时。
