# 设置中心说明

点击客户端右上角的“设置”进入设置中心。后端参数保存后立即生效，不需要手动重启服务。

## 模型 API

- **API 地址**：OpenAI 兼容服务的基础地址，通常以 `/v1` 结尾。
- **API Key**：访问模型服务的密钥。留空表示保持已有密钥不变。
- **对话模型**：负责角色回复、判断是否使用工具并生成工具参数。
- **Embedding 模型**：负责长期记忆向量化。留空时使用无需联网的本地哈希向量。
- **请求超时**：等待模型服务的最长秒数。网络较慢或模型较大时可以提高。

地址、Key 和对话模型三项齐全后，程序会通过模型列表接口检测连接状态；配置不完整或检测失败时不会发送消息，也不会生成占位回复。“保存并测试连接”会先应用当前表单，再执行一次不生成文本的连接检查。

## 生成参数

- **Temperature**：控制随机性。角色扮演建议从 `0.7～1.0` 开始。
- **Top-P**：限制候选词概率范围。一般保持 `1.0`，不要和温度同时大幅修改。
- **最大输出 Token**：限制一次回复长度，也直接影响调用费用。
- **Presence Penalty**：正值鼓励模型引入新内容，过高可能造成剧情跳跃。
- **Frequency Penalty**：正值减少重复用词，过高可能破坏自然表达。

不同服务商不一定支持全部参数。如果接口提示“不支持某字段”，应恢复默认值，或根据该服务文档调整后端请求格式。

## Agent 与记忆

- **最大 Agent 步数**：一轮中模型与工具往返次数的上限。推荐 `4`。
- **近期原文条数**：直接携带的最近消息数量。越高越连贯，但占用更多上下文。
- **RAG 召回条数**：每轮放入上下文的长期记忆上限。推荐 `5`。
- **上下文窗口**：模型支持的总 Token 数。后端先减去“最大输出 Token”，其余才作为输入预算。
- **向量语义权重**：偏向“意思相似”的记忆。
- **关键词权重**：偏向包含相同人物名、物品名和专有词的记忆。
- **记忆重要度权重**：偏向被标记为重要的记忆。
- **时间新鲜度权重**：让较新的记忆获得少量优势。

四项 RAG 权重不要求手动加到 1，后端会自动归一化，但不能全部设为 0。

每轮运行轨迹的 `context_built.token_budget` 会显示角色、世界书、图谱、状态、RAG、摘要和近期原文的占用。已知模型使用对应 tokenizer；无法识别的兼容模型使用保守估算。诊断结果用于上下文裁剪，不等同于供应商账单。

## 写作预设

顶部导航的“预设”用于保存回复的写作方式：

- 主提示词、文风指导、禁写项和历史后指令
- 每条提示词的启用状态、消息角色和发送顺序
- 相对位置或插入聊天记录的 Depth
- SillyTavern JSON 中暂未由当前模型接口使用的额外字段

Temperature、Top-P、Penalty 和 Token 上限仍由“设置 → 生成参数”统一管理。启用预设不会改动这些参数。

角色、主控人物、世界书、长期总结、RAG、场景状态和聊天记录由当前故事决定，不属于预设。导入 SillyTavern JSON 时，这些动态资料槽会被忽略，避免与 Saraswati 的上下文组装重复。

### 上下文调试与费用

“界面与隐私”中的上下文调试模式默认关闭。开启后，故事资料会增加“上下文”页，可以查看本轮实际加入的资料、裁剪记录、世界书触发、RAG 分数和最终 Prompt。页面中的模块可以分别开关。

模型 API 设置可以填写每百万输入与输出 Token 的美元单价。单价为 0 时只记录 Token 和耗时；填写后才计算费用估算。供应商最终账单仍可能因缓存、批处理或专用计费规则而不同。

### 独立 Reranker

- **Rerank API 地址**：支持服务根地址或直接以 `/rerank` 结尾的地址。
- **Rerank 模型**：独立于对话模型和 Embedding 模型。
- **Rerank API Key**：可以使用完全不同的供应商密钥，读取接口只返回末四位。
- **精排候选数**：本地混合初排后送入 reranker 的候选数量，默认 `20`。

请求采用常见的 `{model, query, documents, top_n}` 结构，响应读取 `results[].index` 与 `relevance_score`。未完整配置或单次请求失败时，系统继续使用本地混合分数，不会中断角色回复。

## 界面与隐私

- 墨黑金色和深夜蓝色两套主题。
- `0.85～1.25` 倍的对话文字缩放。
- 紧凑消息间距和减少动画选项。
- 界面偏好保存在浏览器 Local Storage，不进入模型上下文。

聊天、记忆和状态保存在 `data/saraswati_v1.db`，模型设置保存在 `data/settings.json`。两者都被 Git 忽略。读取设置的 API 只返回“是否配置”和末四位提示，不会返回 API Key 明文。

需要注意：`data/settings.json` 是本机明文配置文件，并非系统级加密保险箱。不要把它发送给他人，不要取消对应的 Git 忽略规则。正式产品应改用操作系统密钥环或专门的 Secret Manager。
