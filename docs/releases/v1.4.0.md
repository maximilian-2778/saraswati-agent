# Saraswati Agent 1.4

这次更新补上了长篇故事里很关键的一环：设定会跟着剧情真正发生变化。

当复仇完成、势力覆灭、身份改变这类重要事件已经在正文中明确发生，Saraswati Agent 可以更新当前故事使用的角色、主控和世界书副本。原始资料库不会被改动；存疑的变化会留待确认，已经应用的记录也可以撤销。切换候选回复、改写内容或进入不同分支时，对应设定会重新对齐，不会把另一条剧情线的结果混进来。

另外，这一版加入了前端插件支持和内置的 Tavern Card 兼容插件，补充了 Token 用量与上下文预算显示，并改进了世界书批量管理、SillyTavern 预设与角色卡兼容性。

Windows 版请下载压缩包并完整解压，再运行 `SaraswatiAgent.exe`。已有数据会继续保存在 `%LOCALAPPDATA%\Saraswati Agent`，首次启动时数据库会自动升级。稳妥起见，覆盖旧版本前仍建议备份该目录。
