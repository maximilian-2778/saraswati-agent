# Empty-state artwork

These images are resized copies of public-domain engravings supplied by the project owner.
They are used as randomized loading and empty-conversation artwork.

- `goya-sleep-of-reason.jpg` — Francisco de Goya, *The Sleep of Reason Produces Monsters*, plate 43 from *Los Caprichos*, 1799.
- `durer-melencolia.jpg` — Albrecht Dürer, *Melencolia I*, 1514.
- `durer-saint-jerome.jpg` — Albrecht Dürer, *Saint Jerome in His Study*, 1514.

The copies in this directory are resized to 1400 pixels high for web delivery. The original
downloaded files are not stored in this repository.
